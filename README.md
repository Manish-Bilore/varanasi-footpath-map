# Varanasi footpath potential: web map

**Live:** https://manish-bilore.github.io/varanasi-footpath-map/

Static MapLibre map of footpath potential along the Varanasi road network: candidate patches, zones, existing footpaths and congestion points. Generated by a separate analysis pipeline; this repo holds only the published site.
